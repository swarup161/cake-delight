\# Cake Delight - Setup and Execution Guide



\## 1. Prerequisites



The following software is required to run the Cake Delight application:



\- Java 17

\- Maven

\- MySQL 8

\- Docker

\- Kubernetes

\- kubectl

\- A local Kubernetes environment such as Docker Desktop Kubernetes or kind

\- RabbitMQ

\- A modern web browser



Verify the required tools:



```powershell

java -version

mvn -version

docker --version

kubectl version --client

kubectl get nodes
